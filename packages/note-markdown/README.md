# @knowtis/note-markdown

Markdown ⇄ Tiptap-HTML conversion for the note body, shared by the MCP server (`apps/mcp`) and the API's copilot proposals (`apps/api`). Both sides must agree on one dialect, so there is one implementation.

There is no `package.json`; the package exists as the `@knowtis/note-markdown` alias in `tsconfig.base.json`:

```ts
import { htmlToMarkdown, markdownToHtml } from '@knowtis/note-markdown';
```

## Exports

| Export                     | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `markdownToHtml(markdown)` | CommonMark + GFM tables, task lists (`- [ ]`; the editor holds no list that mixes task and plain items, so one is split into runs of one kind, a numbered run keeps counting where the list was, and a numbered task list becomes the editor's plain task list), a paragraph of nothing but spaces or `&nbsp;` as an empty paragraph, a non-breaking space that opens or ends a text kept, a line of only `&nbsp;` below a hard break that ends a paragraph read as nothing, `==mark==`, `^sup^`, `~sub~`, linkify; a ` ```mermaid ``` ` fence becomes the editor's diagram block (`<div data-mermaid-block data-code>`); an image `![alt](src "caption")` becomes the editor's block figure (`<figure data-image><img><figcaption>`), its alt the label as written with escapes and entities resolved, and one written beside text splits its paragraph into text, figure and text, since the figure is a block; a list item whose first block is not a paragraph (an image, a sublist, a diagram, or nothing at all) opens with the empty paragraph every editor list item needs, so that block stays in the item                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `htmlToMarkdown(html)`     | Inverse for editor-produced HTML: task lists, marks, mermaid blocks and tables survive a round trip; nested task lists keep their nesting, and a task item with no text is written as a bare `- [ ]`, which `markdownToHtml` reads back as a task; an empty paragraph (a blank line in the editor) is written as a line holding only `&nbsp;`, except the one a list or task item opens with, an empty heading as its bare `#` marker, an empty list item as a bare marker and an empty code block as an empty fence, and a diagram stays even when it is all its container holds; a code block's text goes out verbatim and comes back without only the newline the fence syntax adds, while a mermaid block's code drops its trailing newlines, so both directions are fixed points; literal `~`, `^`, `==`, and an `&` that opens an entity reference, are escaped so they stay literal, and a non-breaking space that opens or ends the text of a paragraph, heading or cell is written as `&nbsp;`, which Markdown would not trim. A line break is written as a backslash, and one that ends a paragraph above a line of only `&nbsp;`, since Markdown ignores a break at the end of a paragraph; a heading or table cell holds one line, so a break there cannot survive. A merged cell (`colspan`/`rowspan`) loses its merge — GFM has none — but keeps every cell in its own column; column widths and alignment are dropped. The figure comes back as `![alt](src "caption")`, the alt and caption escaped so they read back literally — `width`/`height` have no Markdown form and are dropped here (the API restores them from the stored body) |
| `TRAILING_NEWLINES`        | The trailing newlines both directions drop from a mermaid block's code; a consumer that keys a diagram by its code drops them the same way                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `BLANK_TEXT`               | A text of nothing but whitespace, `&nbsp;` included, which `markdownToHtml` reads as no text; a consumer comparing documents treats it the same way                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |

The output is **not** sanitized. The MCP writes it through the authenticated notes API; the API's agent sanitizer (`apps/api/src/modules/agent/infrastructure/sanitize/html-sanitizer.ts`) allowlists it before it becomes a proposal.

## Untyped dependencies

`markdown-it-task-lists`, `-mark`, `-sub`, `-sup` and `turndown-plugin-gfm` ship no types. Their declarations live in `src/types/*.d.ts` and reach every consumer's program through the `/// <reference path>` directive at the top of the module that imports them — a source-only package has no other way to hand them over.
